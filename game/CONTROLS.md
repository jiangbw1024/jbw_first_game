# 操作与键位

> 游戏画面不再显示常驻键位提示；本文件是完整的操作说明。
> 键位按“当前场景/模式”区分。同一按键在不同模式下可能承担不同功能。

## 启动与入口

| 启动方式 | 会发生什么 |
| --- | --- |
| `./run.sh` | 打开开始页，自己选「单人进入 / 联机进入」 |
| `./run.sh solo` | 跳过开始页，直接单机（进度存本机，不需要账号） |
| `./run.sh online` | 跳过开始页，直接走联机登录（已记住账号时自动进入） |
| `./run.sh host` | 直接当主机等人连（无账号、无云存档） |
| `./run.sh join 1.2.3.4` | 直接连到某个 IP（无账号、无云存档） |
| `./run.sh both` | 同机开两个窗口，一个主机一个客户端，测联机用 |

- **单机模式**：不需要登录，进度写本机 `user://local_save.json`，不联网。
- **联机模式**：必须先登录；登录后进入**房间菜单**，再自己选「创建房间」或「加入房间」。进度存服务器。
- 两种模式的存档格式完全相同，所以以后加"把单机进度上传到云端"不需要迁移代码。

## 开始页

| 位置 | 说明 |
| --- | --- |
| 「单人进入」 | 不需要账号，进度写本机 `user://local_save.json` |
| 「联机进入」 | 先进登录页，登录后进房间菜单，进度写服务器 |
| 右侧「现场档案」 | 本地档案有没有、上次游玩时间、累计生存时长、当前联机账号 |
| 左下「退出游戏」 | 直接关闭游戏 |

- 右侧那块卡是**只读**的，看一眼不会改动存档。
- 有记住的登录时，提示行会变成「已记住 xxx 的登录 · 选联机将自动进入」。

## 大厅（房间菜单）

| 操作 | 功能 |
| --- | --- |
| 「创建房间（我是主机）」 | 开端口 7777 等人连；本机同时是玩家 |
| 「加入房间」 | 连到上方 IP 输入框里的地址 |
| 「返回主菜单」 | 释放端口，回到开始页重新选模式 |

## 退出当前会话

| 位置 | 操作 | 会发生什么 |
| --- | --- | --- |
| 左上角徽章（`Esc` 释放鼠标后可点） | 联机：「退出登录」 | 存盘 → 清 token → 回登录页 |
| 同上 | 单机：「退出到开始页」 | 存盘 → 回开始页 |
| 房间菜单 | 「返回主菜单」 | 释放 7777 端口 → 回开始页 |
| 游戏内菜单（`Esc`） | 「返回开始页」 | 存盘 → 关会话 / 释放端口 → 回开始页；**不退账号**，点两次确认 |
| 游戏内菜单（`Esc`） | 「退出游戏」 | 直接关闭进程 |

- 单机没有账号可登出，所以徽章上的按钮叫**退出到开始页**，不叫退出登录 —— 文案和实际行为必须一致。
- 想回开始页但**不想登出**时，用游戏内菜单的「返回开始页」（联机同样可用，token 会保留）。
  「退出登录」只在真的要换账号时用。
- 单机徽章不显示「排行榜」：排行榜要账号身份，单机点了只会静默失败。
- 回开始页时会清掉"本次启动意图"（命令行 `--solo` / `--online`），
  否则开始页会以为"命令行已经指定模式"，一帧不停又把你送回游戏 —— 看起来就像退出没生效。

## 基础移动

| 键位 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` | 前 / 左 / 后 / 右移动 |
| 鼠标移动 | 转动视角；垂直视角有上下限，避免翻转 |
| `Shift`（按住） | 冲刺，速度从 5.0 m/s 提升到 8.5 m/s |
| `Space` | 跳跃；只能在地面起跳 |
| `Esc` | 打开游戏内菜单 / 回到游戏；单机（且没有客人）打开即暂停，联机只打开菜单**不暂停**（暂停会把别人一起卡住）；如果聊天、背包、商店等界面开着，优先关闭当前界面 |
| 鼠标左键（鼠标未锁定时） | 重新锁定鼠标，回到游戏操作 |

## 武器与战斗

| 键位 | 功能 |
| --- | --- |
| `1` | 切到主武器 `AK47` |
| `3` | 切到近战武器 `蝴蝶刀` |
| `Q` | 切回上一把武器（`AK47` ↔ `蝴蝶刀`） |
| 鼠标左键 | AK47：开火；蝴蝶刀：轻击 |
| 鼠标右键 | AK47：推击；蝴蝶刀：重击 |
| `R` | AK47 换弹；持刀时无效 |
| `V` | 通用近战攻击，与当前武器槽无关 |
| `F` | 持蝴蝶刀时检视刀具；切枪、死亡或界面占用输入时无效 |
| `L` | 开关手电筒 |
| `H` | 使用急救包；需要背包里有急救包且当前不是满血 |

### AK47

- 全自动，弹匣 30 发，开局备用弹 90 发，备用弹上限 240 发。
- 换弹耗时 2.45 秒；切枪会立即打断换弹，但枪会从当前换弹姿势连续收起，不会先跳回普通持枪姿势。
- 切回 AK47 时会先收刀 0.30 秒，再用 0.55 秒抬枪并拉动拉机柄；拉栓动作结束前不能开火。
- 推击不造成伤害，只把小型敌人向后击退；冷却 0.8 秒。
- `V` 通用近战造成 55 点伤害，范围 2.4 米，冷却 0.62 秒。

### 蝴蝶刀：切换与动画

- 按 `3` 拉刀：先用 0.30 秒收起 AK47，再用 0.45 秒完成蝴蝶刀展开动画。
- 整个切枪过程不能攻击；切枪会取消换弹和尚未结算的重击。
- AK47 → 蝴蝶刀时，AK 会从当前姿态（包括换弹中途）连续下压收起，再拉出蝴蝶刀。
- 切枪途中按回“当前武器”的槽位可以取消切换。例如 AK47 → 蝴蝶刀途中按 `1`，会留在 AK47。
- 持刀时 HUD 右下显示 `蝴蝶刀 / ∞`，不显示弹药数字。
- 持刀且未冲刺时，步行速度 ×1.12；冲刺速度不变。
- `F` 检视：转动刀身并翻动两个刀柄，时长 1.2 秒，纯本地第一人称动画。

### 蝴蝶刀：伤害

| 攻击 | 操作 | 伤害 | 规则 |
| --- | --- | --- | --- |
| 轻击 | 鼠标左键 | 40 | 按住会按 0.45 秒间隔连挥 |
| 重击 | 鼠标右键 | 90 | 有 0.35 秒前摇，命中后进入 0.90 秒冷却 |
| 背刺 | 站在目标背后攻击 | 180 | 按每个目标自己的朝向单独判定 |

- 刀具攻击距离 2.2 米，正前方半角 55 度；锥形范围内的多个敌人会分别受伤。
- 重击冷却从按下右键时开始计算，总冷却 0.90 秒；伤害在 0.35 秒前摇结束时结算。
- 背刺沿用重击的突刺动画，不额外播放另一套动作。
- 敌人默认 100 血：轻击需要 3 刀，重击需要 2 刀，背刺 1 刀。
- 上述数值是当前平衡值，不保证所有敌人一刀必杀。

### 切枪期间的输入

- 切枪期间可以继续移动、转视角、开关手电和使用急救包。
- 切枪期间不能开火、挥刀、推击、通用近战或换弹。
- 切枪最后 0.12 秒内提前点击攻击，拉刀完成后会补一次轻击/重击输入。

## 交互、背包与界面

| 键位 | 功能 |
| --- | --- |
| `E` | 与瞄准的商店老板交易、拾取掉落物、搜刮容器 |
| `Tab` | 打开 / 关闭背包 |
| `Enter` | 打开聊天；输入框内按 `Enter` 发送消息 |
| `Esc` | 关闭聊天 / 背包 / 商店；没有界面时打开游戏内菜单 |
| `H` | 使用急救包 |

- 背包是 4×3 共 12 格；打开背包时会锁定移动、攻击和其他交互。
- 弹药不占背包格，拾取后直接进入 AK47 的备用弹。
- 商店为当前占位版本：点击“购买”不会扣钱，会直接更换第三人称手持物的外观。
- 死亡后 3 秒在出生点复活；死亡会损失一半材料类物品。

## 暂停菜单（仅单机）

| 界面操作 | 功能 |
| --- | --- |
| `Esc` | 游戏中打开菜单；菜单中回到游戏；操作指南中返回菜单 |
| 鼠标点击“继续游戏” | 解除暂停并回到游戏 |
| 鼠标点击“操作指南” | 显示完整键位说明，可滚动查看 |
| 鼠标点击“退出游戏” | 立即关闭游戏进程 |

- 暂停会冻结玩家、敌人、投射物、计时器和所有游戏逻辑。
- 暂停时鼠标会释放，菜单与操作指南都可以直接点击。
- 联机模式**能**打开菜单（否则没有出口），但绝不冻结世界：要离开就用「返回开始页」或「退出游戏」。
- 单机打开菜单会冻结世界；联机只覆盖一层界面，世界继续跑 —— 所以别在丧尸面前慢慢看菜单。

## 建造模式

| 键位 | 功能 |
| --- | --- |
| `B` | 进入 / 退出建造模式 |
| `T` | 让待放置的建筑旋转 90 度 |
| `1` | 选择地基（仅在建造模式生效） |
| `2` | 选择墙（仅在建造模式生效） |
| `3` | 选择门框（仅在建造模式生效） |
| 鼠标左键 | 在瞄准位置放置当前建筑，并按配方扣除材料 |
| 鼠标右键 | 拆除瞄准的建筑，返还一半材料 |

- 建造模式接管鼠标左右键和 `1` / `2` / `3`；此时战斗输入会暂时让路，不会边建造边开枪，也不会按数字键同时切回武器。
- **每种建筑都要材料**：地基 木材 ×2 + 废金属 ×1；墙 木材 ×2；门框 木材 ×3 + 废金属 ×2。
  材料不够时预览变红，底部图鉴里对应卡片也会标红并显示“可造 0”。
- 进入建造模式后，屏幕底部出现**图鉴**：三张卡片分别是数字键、名称、配方和“还能造几个”。
  选中项左侧有一条金色竖条。
- 拆除返还按配方的一半**向下取整**（地基返 1 木材）。拆除底层会让上方失去支撑的部件一起塌落，那些也一并折半返还。
- 对准已有建筑顶面放置，可以向上叠层。
- 城镇范围内禁止建造；水平距离过远、超出世界建筑上限时也不能放置。
- 建造模式下 `E` 交互提示会暂时隐藏，退出建造后恢复。

## 采集

| 键位 | 功能 |
| --- | --- |
| `E` | 砍树 / 搜刮木箱 / 拾取地上的物资 |

- 砍一棵树要 3 下：每下 +2 木材，砍倒那一下额外 +3。
- 砍树用**服务器权威**：距离由服务端按它看到的玩家位置判定，客户端不能远程砍树。
- 木箱一次性搜刮，树砍倒后约 3 秒消失。
- 目前没有斧头物品：`E` 空手砍，因此砍树是“三下换 9 木材”的纯产出动作。

## 联机与启动

- 启动菜单用鼠标点击“创建房间”或“加入房间”，加入房间时在输入框填写服务器 IP。
- 切枪、拉刀、收刀、检视和攻击动画目前只做第一人称本地表现。
- 第三人称角色暂未显示蝴蝶刀模型；其他玩家仍看到原来的手持物。
