## S7.5 建造竖直分层（用户反馈修复）

**问题**：同一格无法往上叠（占位键只有 cell.x/cell.z 两维）。

**方案**：占位键与数据加 `level`（层）维度。
- `_pieces[id] = {kind, cell, level, yaw, base, top, node}`
- `_tops["s:x:level:z"]` = 该层最高顶面高度；`_floor_y()` 无支撑返回 `NAN` → 放置失败
- 客户端只发 `(kind, cell, level, yaw)`，**高度仍由服务器算**
- 瞄准判定：命中顶面 `normal.y>0.6` → level+1；命中侧面 → 同层沿法线移一格；命中地形 → level 0
- 拆除连锁：拆掉下层，同格更高层的块递归移除（确定性代码，各端一致，无需额外网络消息）

**调参**：`REACH_UP` 1.8 → 2.6（1.8 会导致"地基上放 2.4m 墙"被拒，差 0.18m）

**实测**：0层地基/1层地基/1层墙均成功；2层墙与第9层被拒；拆0层后 3 块全部连锁消失
（底高 40.29 → 40.69，差 0.40 = 地基厚度）
